# m3-integration

M3 acceptance tests for `celestia-rs` transaction and ante validation.

This crate is the milestone-level harness for comparing Rust ante outcomes
against Go celestia-app transaction validation results. The 1,062-case app-v6
mainnet corpus is committed. The acceptance entry point remains ignored while
the Rust fixture-backed ante path adds Cosmos SDK storage gas and ordered keeper
events exposed by the first real comparison.

## Depends On

- `ante`

## Consumers

- M3 milestone acceptance gate
- CI once the mainnet transaction corpus is available

## Conformance

The target fixture is `conformance/fixtures/ante/mainnet-tx-corpus.json.zst`,
generated by the `ante-mainnet-tx-corpus` fixturegen scenario. The runner
prefers the compressed corpus for the large mainnet sample, while still
accepting `mainnet-tx-corpus.json` for smaller local corpora. It also requires
the matching `mainnet-tx-corpus.meta.json` provenance sidecar. Run the current
red acceptance gate with:

```bash
cargo test -p m3-integration -- --ignored mainnet_tx_validation_matches_go
```
