# m3-integration

M3 acceptance tests for `celestia-rs` transaction and ante validation.

This crate is the milestone-level harness for comparing Rust ante outcomes
against Go celestia-app transaction validation results. The acceptance entry
point is present, but ignored until the Go-generated 1000-transaction mainnet
corpus is committed.

## Depends On

- `ante`

## Consumers

- M3 milestone acceptance gate
- CI once the mainnet transaction corpus is available

## Conformance

The target fixture is `conformance/fixtures/ante/mainnet-tx-corpus.json.zst`,
generated by the pending `ante-mainnet-tx-corpus` fixturegen scenario. The
runner prefers the compressed corpus for the large mainnet sample, while still
accepting `mainnet-tx-corpus.json` for smaller local corpora. It also requires
the matching `mainnet-tx-corpus.meta.json` provenance sidecar. Once the fixture
is committed, run:

```bash
cargo test -p m3-integration -- --ignored mainnet_tx_validation_matches_go
```
