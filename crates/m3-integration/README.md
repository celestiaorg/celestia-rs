# m3-integration

M3 acceptance tests for `celestia-rs` transaction and ante validation.

This crate is the milestone-level harness for comparing Rust ante outcomes
against Go celestia-app transaction validation results. The acceptance entry
point is present, but ignored until the Go-generated 1000-transaction mainnet
corpus is committed.

## Depends On

- `ante`

## Consumers

- M3 milestone acceptance gate
- CI once the mainnet transaction corpus is available

## Conformance

The target fixture is `conformance/fixtures/ante/mainnet-tx-corpus.json`,
generated by the pending `ante-mainnet-tx-corpus` fixturegen scenario. Once the
fixture is committed, run:

```bash
cargo test -p m3-integration -- --ignored mainnet_tx_validation_matches_go
```
