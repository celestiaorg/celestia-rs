CELESTIA-RS / PRIVACY

Privacy

This website is a set of static pages. It has no accounts, no forms, no cookies, no analytics and no advertising. It does not ask for or store personal data.

Hosting

GitHub Pages serves the site. When you load a page, GitHub receives your IP address and request details as part of normal web serving. The GitHub General Privacy Statement covers how GitHub handles that data.

Node census data

The node census page loads its crawl data from raw.githubusercontent.com, which GitHub also operates. For each public consensus node, the census records the node ID, moniker, software version and app version that the node announces. Nodes publish this information themselves on the Celestia peer-to-peer network. The census does not publish network addresses or collect anything else.

The node software

celestia-rs itself does not send telemetry to the maintainers. The node connects to Celestia network peers, to the RPC servers its operator configures, and to GitHub when it installs or updates a release. See the operator guide for the network endpoints it uses.
