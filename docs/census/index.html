CELESTIA / NODE CENSUS

Consensus nodes by implementation

A crawler connects to the consensus P2P network of each chain and reads the software version that every node reports in its handshake. celestia-rs nodes report 0.38.17-celestia-rs.<version>, which gives their celestia-rs version, such as v0.1.0. Go nodes report only the version of the consensus library they embed, so the crawler reads their celestia-app version, such as v10.6.0, from the node's RPC where that RPC is open.

Method and limits

  • A scheduled GitHub Actions job runs node-census crawl for each network. It dials known addresses, completes the P2P handshake, records the peer's NodeInfo, and asks for more addresses over PEX.
  • It also reads /net_info from public RPC servers. Those list the NodeInfo of their peers, including nodes behind NAT that the crawler cannot dial. “Observed” counts both sources; “direct” counts only nodes that completed a handshake with the crawler.
  • The handshake of a Go node does not carry its celestia-app version. The crawler asks each observed node's own RPC for /abci_info at the RPC address the node advertises (default port 26657). Only nodes with an RPC open to the internet answer; the others are counted as “Unknown (RPC not reachable)”.
  • Nodes that neither accept inbound connections nor peer with a listed RPC server are not seen. The counts are a lower bound.
  • Nodes with any other version string, for example a seed-only crawler, are left out. Bridge and light (DA) nodes use a different network and are not counted here.
  • Data: the node-census-data branch (history.json, latest/<network>.json).
