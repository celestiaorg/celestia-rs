Method and limits
  • A scheduled GitHub Actions job runs node-census crawl for each network. It dials known addresses, completes the P2P handshake, records the peer's NodeInfo, and asks for more addresses over PEX. Rust nodes report 0.38.17-celestia-rs.<version> in the handshake, which gives their celestia-rs version.
  • It also reads /net_info from public RPC servers. Those list the NodeInfo of their peers, including nodes behind NAT that the crawler cannot dial. “Observed” counts both sources; “direct” counts only nodes that completed a handshake with the crawler.
  • When a Go node does not advertise its app release in the peer handshake, the crawler asks the node's own RPC for /abci_info at the RPC address the node advertises (default port 26657). The release stays unknown if neither source supplies it.
  • Nodes that neither accept inbound connections nor peer with a listed RPC server are not seen. The counts are a lower bound.
  • Nodes with any other version string, for example a seed-only crawler, are left out. Bridge and light (DA) nodes use a different network and are not counted here.
