About celestia-rs

celestia-rs is an open-source Rust implementation of a Celestia consensus node. One binary runs a consensus full node or validator, an optional data availability (DA) bridge, and a standalone DA light node. The consensus node is wire- and consensus-compatible with the Go celestia-app and celestia-core. The DA roles interoperate with Go celestia-node.

Who builds it

The project lives in the celestiaorg GitHub organization, next to the Go implementations it is compatible with. All development happens in public on GitHub. The code is dual-licensed under Apache-2.0 and MIT.

Status

celestia-rs is an early, experimental project under rapid development. Expect breaking changes, and do not rely on it for production yet. The project runs a validator on Mocha and Mainnet and publishes its evidence, benchmarks and security notes in the repository. The node census shows how many public consensus nodes run celestia-rs.

This website

This site is the operator guide for celestia-rs: what the node does, how it compares with the Go node, and how to start on Mainnet. It is a static site served by GitHub Pages from the docs/ folder of the repository. The full operator guide covers configuration, upgrades and day-to-day operations.
