CELESTIA-RS / CONTACT

Contact

celestia-rs is developed in public. The fastest way to reach the maintainers is on GitHub, where every issue and pull request is visible to the whole community.

Bugs and questions

Open an issue at github.com/celestiaorg/celestia-rs/issues. For a node problem, attach the archive that celestia-rs debug-bundle writes. It contains the version, configuration and recent logs that the maintainers need. See the operator guide for details.

Security vulnerabilities

Do not file a public issue for a vulnerability. Submit a private security advisory through the Security tab of the repository. If that is not possible, email security@celestia.org. The celestiaorg security policy describes scope and disclosure timelines.

Contributions

Pull requests are welcome. Read the README for build and test instructions before you open one.
