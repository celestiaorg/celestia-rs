# ctypes vectors

Deterministic vectors for the Rust `ctypes` crate (port of celestia-core
v0.42.3 `types/`), generated by celestia-core itself. Output:
`conformance/fixtures/ctypes/*.json.zst` (zstd-compressed JSON, byte strings
as hex, Go error strings verbatim, Go panics as `"PANIC: <msg>"`).

```bash
cd conformance/ctypesvectors
GOPATH=/tmp/claude-0/gopath GOFLAGS=-mod=mod GOTOOLCHAIN=go1.26.6 go run . -out ../fixtures/ctypes
```

| File | Content |
|---|---|
| `headers` | header hashes, `ValidateBasic`, `HeaderFromProto` |
| `blocks` | random blocks (blob / index-wrapper txs, evidence, celestia data root and square size): block hash, `MakePartSet` (64 KiB and 1000 B) with tx positions, size, re-encoding; malformed blocks' `BlockFromProto` errors |
| `partsets` | `NewPartSetFromData`, part proofs, `AddPart` outcomes for tampered parts, `PartFromProto` |
| `votes` | vote / extension / proposal sign bytes, `ValidateBasic`, `Verify*`, commit-sig conversion, `String` |
| `commits` | `VerifyCommit`, `VerifyCommitLight[AllSignatures]`, `VerifyCommitLightTrusting[AllSignatures]` over ed25519 / secp256k1 / mixed sets (batch and single paths), with bad / short / missing signatures, wrong addresses, double votes, insufficient power, bad trust levels |
| `valsets` | proposer-priority evolution: `IncrementProposerPriority`, `UpdateWithChangeSet` (valid and invalid change sets), copies, proto round trips, `ValidatorSetFromExistingValidators`, `RescalePriorities` (incl. Go's `TestProposerSelection1-3`) |
| `evidence` | duplicate-vote and light-client-attack evidence: hashes, ABCI misbehavior, validation, `GetByzantineValidators`, evidence-list hashes |
| `params` | consensus-param hashes, `ValidateBasic`, `ValidateUpdate`, `Update` |
| `txs` | `Tx.Hash` / `Tx.Key` (incl. malformed `IndexWrapper` / `BlobTx` encodings), `Txs.Hash`, tx proofs, results hashes |
| `misc` | `MaxDataBytes`, time and duration formatting, `WeightedMedian`, `BlockID` |
| `real-blocks-<scenario>` | blocks from a Go devnet's block store (block hash, part set, tx positions, validator / params hashes, commit verification) |

Real blocks come from a devnet run (`conformance/devnet/devnet.sh`) with
`CTYPES_BLOCKS=1` (also writes the devnet fixture) or `CTYPES_ONLY=1`:

```bash
DEVNET_BIN=/tmp/claude-0/bin CTYPES_ONLY=1 conformance/devnet/devnet.sh blob 30 conformance/devnet/workloads/blob.sh
# or from any stopped celestia-core data dir (pebbledb):
go run . -out ../fixtures/ctypes -blockstore <home>/core/data -scenario <name>
```
